# Outputs

This directory contains compact summary outputs that document the final rerun. The complete set of generated diagnostics is produced by running `notebooks/final_analysis.ipynb` or `src/forecasting_digital_divide.py`.

The full pipeline writes model comparisons, ARIMA/ETS selection diagnostics, horizon diagnostics, clustered bootstrap results, feature-importance diagnostics, VIF/correlation tables, lag ablation, weight sensitivity, country trajectory sensitivity, Kazakhstan scenarios, filtering summaries, and figures.
